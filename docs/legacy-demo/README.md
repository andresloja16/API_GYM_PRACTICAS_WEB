# Prototipo estático anterior

Esta carpeta conserva el primer dashboard HTML/CSS/JS, con datos de demostración en `localStorage`. Abre `dist/index.html` para consultarlo.

La aplicación actual está en `GymApi/` y `frontend-app-ing-web/`, conectada a la API. No ejecutes `server.cjs` de este prototipo mientras la API usa el puerto 3000.
